# AGENT-NOTES.md — Task W2 (web application)

## What was built

**Oryx Ecosystem** — a single Next.js 16 (App Router, TypeScript, Tailwind CSS 4) web app
producing a **pure static export** (`output: 'export'`, `trailingSlash: true`,
`images.unoptimized`). No database, no server routes, no Prisma, no API routes, no auth.
All state lives in `localStorage`; all PDFs and QR signing happen client-side.

Two brand tracks + one public portal:

| Route | Track | Contents |
|---|---|---|
| `/` | neutral | Landing with two large track cards |
| `/safeman/` | green | Dashboard: mandatory disclosure callout, 13-course grid |
| `/safeman/course/[id]/` | green | Module reader (diagrams, key points, video slots, manual PDF) |
| `/safeman/course/[id]/quiz/` | green | Auto-graded MCQ engine, deterministic seeded paper, explanations |
| `/safeman/course/[id]/practicum/` | green | Assessor sign-off: checklist + canvas signature pad (locked until quiz pass) |
| `/safeman/issue/` | green | Certificate issuer → jsPDF A4 + 2-sided 85.6×54 mm PVC passport card + HMAC-signed QR |
| `/verify/` | public | HMAC re-computation portal, green VALID / red INVALID panels, paste-box, offline |
| `/oryx/` | maroon | NQF Levels 1–7 explorer, NTA alignment matrix, manual + assessment-pack downloads |
| `/oryx/lab/` | maroon | 4-gas detector simulator (statutory alarms + bump test), TWA 8h/12h, noise dose (85 dBA / 3 dB), WBGT work/rest table |

All 13 SafeMan courses and 7 Oryx levels render straight from
`public/data/safeman_courses.json` / `public/data/oryx_nqf_levels.json` (imported at build
time — zero runtime data fetches). Nothing hardcoded.

## Design token compliance

- Oryx maroon `#6A1B29` / hairline `#D9CFC0` / accent `#B89B72` / canvas `#FAF6F0` /
  callout `#F5EFE6` + 3 pt left border; SafeMan green `#14532D` / accent `#16A34A` /
  callout `#F0FDF4` + 3 pt left border, hairline `#C6D8C8` — defined once in `globals.css`
  `@theme`, consumed as Tailwind utilities (`bg-oryx-primary`, `border-safeman-hairline`, …).
- Radley = display/headings only (`font-display`); Inter = body/UI/tables; every numeral
  uses `.tnum` (Inter + tabular figures) — Radley never renders digits.
- Contact is `info@oryxinstitute.org` only — no phone, no P.O. Box, no copyright lines.

## Known limitations / adaptations

1. **Manual PDFs for L4–L7 and most SM-* course manuals** are linked by path exactly as the
   JSON specifies; some files are still generating on disk, so those links 404 until the
   document pipeline lands (per task instructions: link regardless).
2. `video_demo_url` is `null` throughout the dataset → the mandated "Practical Video
   Recording Scheduled — Follow Step-by-Step Illustrated Checklist Below" badge renders; a
   real `<video controls>` player appears automatically if a URL is ever added.
3. Serial sequence numbers derive from the local ledger (per browser), so two devices can
   produce the same seq — acceptable for an offline-first tool; the webhook relay (optional
   `NEXT_PUBLIC_WEBHOOK_URL`) is the reconciliation point.
4. QR payloads use the production domain `safeman.oryxinstitute.org/verify?…` (per spec); a
   local "Test in verification portal" link is provided next to every issued record.
5. Alarm thresholds in the 4-gas sim are the industry-standard statutory set-points
   (O₂ 19.5–23.5 %, LEL ≥ 10 %, CO ≥ 35 ppm, H₂S ≥ 10 ppm); the WBGT table is an
   ACGIH-style screening aid and says so on screen.
6. `npm run lint` is `tsc --noEmit` — ESLint was deliberately not added (dependency
   whitelist). Next 16 no longer runs ESLint during `build` anyway.
7. Sandbox preview: a read-only copy of `out/` is served on port 4173 with a tiny
   gateway bridge injected so it can be browsed through the sandbox proxy. The bridge lives
   in `agent-ctx/W2/preview-tools/`, **not** in this repo — deploy `out/` as-is.
