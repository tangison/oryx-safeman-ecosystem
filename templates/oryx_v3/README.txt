ORYX INSTITUTE: PRINT TEMPLATES (structured edition)
====================================================
FIRST: install the fonts in 03_Fonts (Radley, Inter 24pt). They are also embedded in each file.
START WITH: 00_Template_System_Guide.docx. It sets out the rules every file follows.

HOW THE FILES ARE BUILT
- Every file uses named Word styles (Home > Styles): Heading 1/2/3, Oryx Body, Oryx Eyebrow,
  Oryx Lead, Oryx Caption, Oryx Quote, Oryx Table, and so on. Use them; do not format by hand.
- Every document: cover, front matter, numbered body sections, back matter, back cover.
- Contents pages are linked to the headings. After editing, click the contents page and press F9
  (or right-click > Update Field) to refresh the page numbers.
- Textbook: front matter in roman numerals, chapters in arabic numerals.

All names, figures and dates are DEMO DATA. The cover photograph is about 120 dpi at A4;
use the original at 300 dpi or more for final print. Add 3 mm bleed before sending to a printer.
